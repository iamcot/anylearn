# Prompt cây trồng – Nông trại anyLEARN (bản dán thẳng)

Mỗi khối ``` dưới đây là **một prompt hoàn chỉnh**, đã có sẵn đoạn style chung, bảng màu và yêu cầu nền trong suốt. Chỉ cần copy cả khối, dán vào công cụ ảnh. Không phải ghép gì.

Cách dùng:
1. Vẽ **Cà rốt cầu vồng trước** (4 khối đầu tiên, không cần ảnh tham chiếu). Ưng rồi mới vẽ các cây còn lại **trong cùng một cuộc chat** vì các prompt sau nhắc "carrot images in this chat" để giữ nét.
2. Với mỗi cây, vẽ lần lượt Mầm, Lớn, Chín, Sản phẩm (đừng đảo thứ tự, các khối sau nhắc "previous image").
3. Ô có ô **Negative prompt** thì dán khối "Negative prompt" ngay dưới đây. Công cụ không có ô này thì bỏ qua, prompt đã tự nói "no text".
4. Kích thước: ảnh cây 512×512, ảnh sản phẩm vẽ 1024×1024 rồi thu nhỏ còn 256×256. Công cụ không xuất nền trong suốt: thay "transparent background" bằng "plain solid white background" rồi xóa nền.
5. Tên file gợi ý ghi ở tiêu đề mỗi khối: `<cropKey>_seedling.png`, `_growing.png`, `_ripe.png`, `_product.png`.

## Negative prompt (dán một lần vào ô negative)

```
text, letters, numbers, watermark, signature, logo, realistic, photorealistic, 3d render, plastic, pixel art, horror, scary, dark gloomy, sharp spikes, gore, weapons, thin scratchy lines, messy sketch, cluttered background, harsh shadows, cropped object, extra limbs, deformed character
```
